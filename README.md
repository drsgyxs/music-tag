# 音乐标签编辑器

这是一个基于HarmonyOS开发的音乐标签编辑器应用，可以读取、查看和编辑音频文件的元数据信息。

## 功能特性

- **音频文件选择**：通过系统文件选择器选择音频文件
- **元数据读取**：读取音频文件的标签信息，包括：
  - 标题、艺术家、专辑
  - 作曲家、词作者、专辑艺术家
  - 发行年份、音乐类型、音轨号
  - 专辑封面、内嵌歌词
  - 文件信息（格式、大小、时长等）
- **标签编辑**：编辑音乐标签信息
- **封面管理**：查看和更换专辑封面
- **数据存储**：将编辑后的元数据保存到应用本地存储
- **数据导出**：将元数据导出为JSON、TXT或CSV格式

## 技术架构

- **HarmonyOS API**：使用MediaKit读取音频元数据
- **FilePicker**：使用系统文件选择器
- **Preferences**：本地数据存储
- **ImageKit**：图像处理

## 开发说明

由于HarmonyOS当前版本的API限制，应用无法直接修改音频文件的元数据。但是提供了以下替代方案：

1. 将编辑后的元数据保存到应用本地存储
2. 支持导出元数据为多种格式
3. 用户可以使用PC端专业工具（如Mp3tag）进行实际的标签修改

## 使用方法

1. 启动应用
2. 点击"选择音频文件"按钮
3. 从系统文件选择器中选择一个音频文件
4. 查看和编辑音乐标签信息
5. 点击"保存"将编辑结果保存到本地存储
6. 点击"导出"将元数据导出为文件
